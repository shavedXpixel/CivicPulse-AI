## 1. Current Verified Architecture

CivicPulse AI is operating strictly in **REAL_MODE** (`DEMO_MODE=false`, `PROVIDER_MODE=cloud`) with the following authoritative target production stack:

- **Frontend**: Next.js 15 (App Router, Standalone output) deployed to **Vercel**
- **Backend API**: Express + TypeScript Node.js service deployed to **Render Web Service** (Singapore region)
- **Authentication**: **Supabase Auth** (ES256 asymmetric JWT verification via JWKS, `JWT.sub -> public.users.auth_user_id`, no email runtime linking)
- **Database**: **Supabase PostgreSQL 17.6** with `pgvector`, `uuid-ossp`, and `pgcrypto` extensions
- **Object Storage**: **Cloudflare R2** (S3-compatible, private bucket `civicpulse-media` with pre-signed uploads and secure API streaming)
- **AI Engine**: **Google Gemini** (Primary: `gemini-3.6-flash`, Fallback: `gemini-3.5-flash`, Embeddings: `text-embedding-004`)
- **Maps / Reference Data**: Existing local BMC Ward GeoJSON & Census datasets (no external Mapbox dependency)
- **Repository Visibility**: Strictly **PRIVATE** (`https://github.com/shavedXpixel/CivicPulse-AI.git`)

### Provider Container Resolution
When configured with target production variables:
- `AUTH_PROVIDER=supabase` $\rightarrow$ `SupabaseAuthProvider`
- `DATABASE_PROVIDER=postgres` $\rightarrow$ `PostgresDatabaseProvider`
- `STORAGE_PROVIDER=r2` $\rightarrow$ `R2StorageProvider`
- `AI_PROVIDER=gemini` $\rightarrow$ `GeminiAIProvider` & `GeminiVerificationProvider`
- `DEMO_MODE=false` $\rightarrow$ All mock and local providers are strictly forbidden and fail closed (`AppError(500)`).

1. **API Key**: `GEMINI_API_KEY` required at startup when `DEMO_MODE=false`.

## 9. CORS Verification

1. **Wildcard Rejection**: `validateRealModeConfig` explicitly rejects `CORS_ALLOWED_ORIGINS` containing `*` in REAL_MODE.
2. **Explicit Matching**: Express `cors` middleware tests incoming `Origin` against `env.CORS_ALLOWED_ORIGINS`.
3. **Credentials**: `credentials: true` is strictly enforced with specific allowed origins.
4. **Deployment Override**: On Render, `CORS_ALLOWED_ORIGINS` will be set to `https://<vercel-deployment>.vercel.app`, preventing local defaults from applying in production.
